# Attribution — Model vs. Deterministic Code

In accordance with **Rule 1 (Deterministic code owns the numbers; the model owns judgment and words)** and **Section 10 (`ATTRIBUTION.md`)**, this document records the exact boundary between what the AI model / coding agent produced and what deterministic TypeScript code computes and renders at runtime.

## 2. Public Honesty Checklist

1. **Zero LLM arithmetic:** Every dollar amount, percentage, visit count, streak length, and query result displayed anywhere in the application is computed by deterministic TypeScript code over integer cents (`amount_minor`).
2. **100% receipt traceability:** Every chapter and metric block exposes its backing `txn_ids` via the interactive Receipts Drawer (`src/explore/receipts-drawer.ts`).
3. **Offline reproducibility:** With no network connection and no API key, `npm run pipeline`, `npm run story`, `npm run check`, `npm run dev`, and `npm run capture` produce identical, deterministic outputs.
